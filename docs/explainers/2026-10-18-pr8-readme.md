# Stack 8/8: the README

## Summary
This PR writes the README. It opens with the task and the score, then shows each command's real output with a
short reading of it. Then it covers what is in the repo, how to run it, the layers, and the limits.

## How it works
Every console block in the README is the output of the command above it. A check reruns each command except
`el ann` and compares the output. The ANN timings vary between runs, so that block shows the saved run that
the results page also uses.
